Mining

This page does not mine, and nothing in this project mines in a browser. Hearth's proof-of-work (Homefire) is memory-hard and runs in hearthd.

Mining is also non-outsourceable: the coinbase public key is hashed into the proof-of-work seed, so a node can only mine to a key it actually holds. Pointing --miner-address at an address the node has no key for silently mines to the node's own wallet instead. To mine to this address, give the node this key — export it below, append it to data/wallet.json, then:

node bin/hearthd.js --mine --miner-address …

Mined coins are locked for 10 blocks before they can be spent; until then they show up above as maturing.

Your key

The private key is stored unencrypted in this browser's localStorage under hearth.wallet.v1. Anything that can read this browser profile can spend these coins. Clearing site data destroys the key and the coins with it. Treat this as pocket money and keep a backup.

What this wallet does and doesn't do

Does

Generates an Ed25519 key locally · derives a checksummed ember1 address · reads real balances and UTXOs from the node · builds, signs and broadcasts real transactions · shows the node's own txid and waits for the block that contains it.

Doesn't

No mining · no encryption at rest · no seed phrase or multi-address HD derivation (one key per browser) · no transaction history beyond the current UTXO set and mempool · no fee estimation beyond the fixed base fee · no hardware wallet support.

Hearth Wallet · a CloudsForge product · keys are generated and signed in your browser and are never sent to the node · this page does not mine
