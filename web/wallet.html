Create or import a key

It is then sealed with AES-256-GCM under a key derived from the passphrase below, and only the sealed form is written to this browser. The passphrase is never stored and cannot be recovered.

Mining

This page does not mine. To mine to this address in a browser tab, open the miner — it uses this same key. To mine with a full node instead, Hearth's proof-of-work (Homefire) is memory-hard and runs in hearthd.

A block's proof must be signed by the key its coinbase pays, so a node can only mine to a key it actually holds. Pointing --miner-address at an address the node has no key for silently mines to the node's own wallet instead. To mine to this address, give the node this key — reveal it below, append it to data/wallet.json, then:

node bin/hearthd.js --mine --miner-address …

Mined coins are locked for 10 blocks before they can be spent; until then they show up above as maturing.

Your key

The private key is stored in this browser's localStorage under hearth.wallet.v2, sealed with AES-256-GCM under a key derived from your passphrase by PBKDF2-HMAC-SHA256 at 600,000 iterations. The passphrase is not stored anywhere, so a copy of this browser profile is not enough to spend these coins — and nobody, including us, can open the key for you if you forget it. Clearing site data destroys the key and the coins with it. Keep a backup.

What this wallet does and doesn't do

Does

Generates an Ed25519 key locally · derives a checksummed ember1 address · seals the key at rest with AES-256-GCM behind a passphrase · reads real balances and UTXOs from the node · builds, signs and broadcasts real transactions · shows the node's own txid and waits for the block that contains it.

Doesn't

No mining (that is the miner) · no seed phrase or multi-address HD derivation (one key per browser) · no passphrase recovery of any kind · no transaction history beyond the current UTXO set and mempool · no fee estimation beyond the fixed base fee · no hardware wallet support.
