Mine EMBER in this tab

Homefire is CPU-only and non-outsourceable: the winning hash has to be signed by the key the reward pays. There is no pool to join, because work handed to you is worth nothing to anyone else. Your key stays in this browser — only the signature ever leaves it.

Where the reward goes

Mining needs a key to pay. This page uses the same one as the wallet, stored in this browser under hearth.wallet.v1.
