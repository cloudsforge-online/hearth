Mine EMBER in this tab

Homefire is memory-hard and CPU-friendly, and the winning hash has to be signed by the key the reward pays — so work handed to you cannot be redirected to anyone else. Your key stays in this browser, sealed with a passphrase; only the signature ever leaves it.

Politeness is real, not a slogan: the effort slider below is a duty cycle the workers actually sleep through, a background tab drops to a trickle, and where the browser reports it, mining pauses the moment you unplug.

Where the reward goes

Mining needs a key to pay. This page uses the same one as the wallet — one secp256k1 key, stored in this browser under hearth.wallet.v3 and sealed with AES-256-GCM under a passphrase you choose. The passphrase is never stored and cannot be recovered.

Open the wallet

This browser holds the sealed key for . Mining signs every winning digest with it, so it has to be unlocked first.

The key in this browser is an Ed25519 key from the pre-EVM chain. It cannot be mined to: a block's proof is now signed with secp256k1, and the coinbase has to be an account this chain can credit (docs/evm-spec.md §4). There is no way to convert one kind of key into the other, and that chain has been reset, so it holds nothing.

Nothing has been deleted. Open the wallet to create a key for this chain, then come back — mining will work straight afterwards.
